### Dataset Description
### A representative subset of the datasets is publicly released. 

#### COVID-19
###### This dataset, which we constructed ourselves, includes the tweet discourse of Korean people mentioning COVID-19 vaccine brands during the pandemic. To build this dataset, we collected Korean tweets mentioning at least one keyword, such as ‘Novavax,’ ‘Moderna,’ ‘AstraZeneca,’ ‘J anssen,’ and ‘Pfizer,’ via the Twitter API. We set our collection period from February 2021, when the COVID-19 vaccination rollout plan was announced and started, to July 2021 in Korea. 

#### 20 Newsgroups
###### This is a well-known dataset used for text classification and clustering experiments. The dataset has 18,846 newsgroup posts on 20 different newsgroups. As a preprocessing step, we discarded numeric tokens and punctuation, tokenized texts using PorterStemmer, and removed stopwords

#### PubMed
###### This dataset consists of the PubMed abstracts and titles concerning Type 2 Diabetes Mellitus. For evaluation, we used the portion of the abstracts in this dataset.

#### Yelp
###### This dataset is a subset of businesses, reviews, and user data for use in connection with academic research. We extracted and utilized the portion of this dataset related to Korean food.

#### arXiv
###### This dataset consists of the arXiv paper abstracts, titles, and terms about Computer Science. We utilized some abstracts related to Machine Learning and AI in this dataset.

#### Korean Petition
###### This dataset comprises Korea-related petitions across 17 categories. For our analysis, we selected petitions from politics, foreign affairs, public administration, human rights, and gender equality. To ensure relevance, we included only petitions with more than 100 agreements.

#### Reuters-21578
###### This dataset contains 21,578 newswire articles collected from Reuters. Each document is annotated with one or more labels drawn from a set of 135 possible topics. Due to its rich multi-label annotations and imbalanced class distribution, the dataset is widely used for benchmarking text classification and topic modeling tasks.

#### Amazon Review
###### This dataset contains product reviews and metadata from Amazon, comprising over 130 million reviews across various categories. For our domain-specific analysis, we use a subset from the software category.

#### DBpedia 
###### This dataset comprises short descriptions of Wikipedia entities annotated with ontology-based classes. These descriptions support text classification, semantic typing, and knowledge base population.
